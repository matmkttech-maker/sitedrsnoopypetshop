# Dr. Snoopy Pet Shop - Abrantes

Landing page responsiva, estática e mobile-first, publicada com GitHub Pages.

Endereço de publicação: https://matmkttech-maker.github.io/sitedrsnoopypetshop/

## Estrutura

- `index.html`: conteúdo, metadados e dados estruturados VeterinaryCare/LocalBusiness e FAQPage.
- `styles.css`: layout responsivo em laranja e teal.
- `app.js`: menu e mensagens do WhatsApp.
- `assets/`: fotos ilustrativas e capturas de avaliações fornecidas pelo solicitante.
- `robots.txt`, `sitemap.xml`, `llms.txt`: arquivos de apoio aos mecanismos de busca e leitura por IAs.

## Hospedagem

GitHub Pages: publicar a branch `main`, pasta `/(root)`. Não é necessário instalar dependências ou compilar. `.nojekyll` permite servir diretamente os arquivos estáticos. Atualizações nessa branch geram nova publicação.

Ao configurar um domínio próprio, atualize canonical, og:url, os identificadores e URLs nos JSON-LD, sitemap.xml, robots.txt e llms.txt.

Como este é um site de projeto em um subdiretório de github.io, seu robots.txt está disponível no caminho do projeto; mecanismos aplicam regras de robots.txt na raiz do domínio, não de cada subdiretório. O sitemap pode ser enviado diretamente ao mecanismo de busca. O llms.txt é informativo e não garante citações.
